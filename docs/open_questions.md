# docs/open_questions.md

Рабочий документ. НЕ канон. Канон — в `docs/canon/` и `docs/scenes/`.
Если открытый вопрос противоречит канону — канон побеждает, вопрос помечается `DROPPED`.

## Протокол для агента
- Новый открытый вопрос дописывается в конец нужной группы с следующим ID. Не перенумеровывать.
- Не отвечать на открытый вопрос молча. Только задать, уточнить, предложить варианты — решение за автором.
- Одна строка на вопрос, максимум две. Без прозы.
- Когда автор решил: строка переезжает в блок RESOLVED с одной строкой решения и указателем, где теперь лежит решение (`см. docs/scenes/...`). На старом месте остаётся заглушка `Qxx → RESOLVED`.
- Когда автор отказался: переезжает в DROPPED с причиной в одну строку.
- Решать по одному вопросу за сессию. Не оптом.

## Статусы
`OPEN` — думать. `THINKING` — автор взвешивает, варианты на столе. `LOCKED` — намеренная амбивалентность, не трогать. `RESOLVED` — решено, указываете куда. `DROPPED` — снято с повестки.
