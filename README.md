# README.md

# Depth-10

Психологический хоррор от первого лица. Эстетика low-poly PS2 / analog horror.
Зима, ноябрь–декабрь 2006. Постсоветская промышленная инфраструктура.

Внутриигровое русское название объекта — «Глубина-10». Техническое имя проекта — Depth-10.

## Стек

- Движок: Redot 26.3 (форк Godot 4), рендерер Forward Plus
- Язык: GDScript. C# не используется
- Целевая платформа: PC
- Внутреннее разрешение рендера: 640×360, апскейл nearest

## Запуск и проверка

### Смоук-тест движка

Проверяет, что Redot запускается и выполняет GDScript. MCP не затрагивает.

```
redot.windows.editor.x86_64.llvm.console.exe --headless --script "res://scripts/smoke.gd" --path "<путь к проекту>"
```

Ожидание: в выводе `depth-10 ok`, код выхода 0.

### Смоук-тест MCP (агент ↔ движок)

Проверяет связку агента с Redot. Выполняется из Kilo Code после подключения.

1. В пикере MCP-контроллеров видны пять инструментов Redot:
   `redot_scene_action`, `redot_resource_action`, `redot_code_intel`,
   `redot_project_config`, `redot_game_control`.
2. Запросить: `redot_code_intel(action="validate", path="res://scripts/smoke.gd")`.
3. Ожидание: ответ без ошибок валидации; `get_docs` возвращает документацию класса.

Среда считается готовой к первым задачам только после обоих тестов.

## Как здесь работают с AI

Правила лежат в `AGENTS.md` и обязательны:
- один запрос = одна логическая задача (сцена + её скрипт + материалы считаются одной); несвязанные правки не смешиваются
- формат ответа: изменённые файлы, 3 шага ручной проверки, что может сломаться
- `.tscn`: точечно — `redot_scene_action`, массово — скрипт-генератор; ручная правка текста запрещена
- код не коммитится, пока не прошёл `validate`
- после каждого работающего состояния — коммит
- планы: активные в `plans/`, завершённые — в `plans/archive/` со статусом (архив вне семантического индекса)
- чтение файлов — по релевантности (см. AGENTS.md)
- `redot_code_intel get_docs` — только при неопределённости (см. AGENTS.md)

## Дизайн

Игра спроектирована документами в `docs/`. Они — источник правды.
Любое отклонение от канона требует явного решения автора, а не молчаливой правки.

Ключевые принципы (подробнее в docs):
- ни одного лица в кадре, включая лицо героя
- HUD отсутствует, информация диегетическая; субтитры — не HUD, включены по умолчанию
- один мотивированный источник света на помещение
- звук несёт основную нагрузку; сцена обязана работать с закрытыми глазами
- свет врёт о цвете: натриевые лампы монохромны, фонарик возвращает истину
- одна концовка
