# План: SC-001 «Подписание» — реализация по спецификации

> **Статус: активен.** 2026-11-19. Решение по конфликту: фон при открытии папки притемняется + виньетка; blur/DOF не используются. Перчатки: без перчаток (решение архивного плана `archive/1795074245262-sc001-signing-blockout.md`).

## Цель
Реализовать биты 01–09 и все взаимодействия из `docs/scenes/SC001_signing.md`: оверлей документа с четырьмя страницами, перелистывание, взятие ручки, подпись с порогом 72%, TAPS, LIGHTS_OUT, END и foley. Сцена проходится без HUD-текста; субтитры — только диалог, не HUD.

## Что уже есть
`scenes/SC001_Blockout.tscn` и `scripts/sc001_signing.gd`: комната, стол 150×100×75, лампа, папка, ручка, силуэты Дяди и охранника, обзор ±35° yaw / ±15° pitch, постукивание пальцем, мерцание лампы, процедурный гул, fade-in. Есть три WAV-записи стука.

## Архитектура

### Слои
World (3D) → `DocumentLayer` (CanvasLayer 5) → `SubtitleLayer` (CanvasLayer 6) → `FadeLayer` (10).

### Режимы ввода
- `LOOK`: мышь захвачена, камера в конусе, точка 2×2 в центре; клик по спроецированному прямоугольнику папки/ручки.
- `DOC`: камера заморожена, мышь видима (кастомный курсор), документ наклоняется за курсором; Esc или клик вне листа закрывает. Переход — твин от `camera.unproject_position(папка)` к центру и обратно.
- Кастомный курсор: точка 2×2, над интерактивной зоной — 6×6; системный курсор скрыт.

### Состояния и флаги
`INTRO → IDLE → FOLDER_OPEN ↔ pages → PEN_TAKEN → SIGNING → SIGNED → LINE_2 → TAPS → LIGHTS_OUT → END`.

Флаги: page 3 → `treatment_leverage_seen`; page 4 → `read_contract`; ручка → `pen_taken`; покрытие ≥72% → `signed_contract`; LINE_1 → `met_somov_voice`.

### Документ
2D-оверлей, не 3D-проп. Причины: читаемость на 640×360, Line2D-чернила и бины без проецирования на 3D, простые зоны наведения, наклон и возврат на стол твинами Control. Минус: лампа не освещает бумагу — тон PAPER и тёплый градиент запекаются в текстуру. Переход «поднимается со стола» — от проекции папки к центру; 3D-папка скрывается на время открытия.

Читаемость: страница 190×268 логических px (≈74% высоты) внутри 640×360, тело 11 px, заголовок 13 px, подписи полей 8 px. Текст только ключевой, без юридической воды. Размер и координаты подбираются по кадрам.

### Страницы
4 страницы `Page1..Page4` внутри `Paper` — Label-строки с `SystemFont` (Courier New / Liberation Mono), AA выключен, субпикселинг выключен, мипмапы выключены. Текстуры PNG не нужны: на 640×360 текст остаётся резким, а ассеты не требуются. Сцена собирается генератором `tools/build_sc001_document.gd` (массовая сборка дерева по AGENTS).
1. Договор подряда — ПОДРЯДЧИК Орлов К.А., ОБЪЕКТ Глубина-10.
2. Условия работы — СРОК 2–3 недели, АВАНС 500 000 руб., обязательства.
3. Особые условия — субъект А-0427-О, прогноз нестабилен, терапия Анны.
4. Подписание — согласие, строка подписи, штамп СОГЛАСОВАНО, дата 12.11.2006 (скрыта до подписи).

### Перелистывание
Второй TextureRect-лист едет поверх текущего (0.35 с, лёгкий наклон 2°), затем свап текстуры. Зоны 20 px по краям, ReferenceRect 1 px приглушённо-белым; на первой левая зона выключена, на последней правая. Колёсико игнорируется.

### Наклон бумаги
Наклон боков — shear по Y вокруг центра листа, не вращение в плоскости экрана. `Paper` лежит в `Node2D` `PaperPivot` (центр листа в локальном нуле), пивот получает `Transform2D(Vector2(1,0), Vector2(k,1), position)`. `SHEAR_MAX = 0.05`, `SHEAR_SPAN = 90` (от центра листа), сглаживание 8.0. У `Control` в 26.3 нет `skew`, поэтому shear через `Node2D`; на 3–5° от перспективы неотличимо. Реальная перспектива (SubViewport + шейдер) отложена как ненужное усложнение.

### Подпись
Линия в локальных координатах страницы, 20–25 бинов. Line2D — ребёнок страницы с `clip_contents`, поэтому наклон и клип наследуются. Зажатие в зоне строки → точки, бины по x, скрип пера по скорости; отпускание → coverage = bins/N, ≥0.72 принимаем. Неудачный штрих остаётся, бины накапливаются, повтор без текста. При успехе дата проступает, ставится `signed_contract`, играет LINE_2.

### Ручка
Space в `DOC` на page 4 или клик по ручке в `LOOK` после `read_contract`. 3D-ручка скрывается; 3D-руки остаются в мире, но за оверлеем их не видно. Видимый хват «ниже обычного» — отдельный арт-проход (2D-спрайт руки поверх документа), не блокер интерактива.

### Диалог
LINE_1 и LINE_2 — субтитры в `SubtitleLayer`, 8×16 без AA, без метки источника (Q24 открыт, один говорящий). Бит 00 без текста. Голос не добавляем: Q22 не решён, субтитры остаются основным каналом. LINE_1 ставит `met_somov_voice`; длительность по времени чтения.

### Звук
- Гул лампы — существующий генератор.
- One-shot'ы (папка, ручка, выключатель, стул, дверь, мотор) — сначала синтез `AudioStreamWAV` в рантайме; финальные WAV `SFX_[cat]_[name]_[nn]` — отдельным проходом.
- Перо — генератор 2.2–4 кГц с гейтом по движению.
- Ducking −6 dB — runtime-шина `SC001` для мира; чернила и бумага не глушатся.
- TAPS 3+3 — scripted-очередь на существующем `tap_player`, затем случайный стук выключается.
- LIGHTS_OUT: щелчок → лампа и гул за 0.1 с → стул/дверь/мотор → чёрный 2 с → `scene_finished`.

### Скрипты (≤150 строк)
- `scripts/sc001_signing.gd` — оркестратор, состояния, режимы ввода, биты, субтитры, lights-out.
- `scripts/sc001_document.gd` — оверлей, страницы, перелистывание, наклон, чернила, бины.
- `scripts/sc001_foley.gd` — синтез one-shot'ов, скрип пера, ducking.
- Мерцание и lights-out можно оставить в оркестраторе.

### Сцена
`scenes/SC001_Blockout.tscn`: добавить `DocumentLayer` с инстансом `scenes/SC001_Document.tscn`, `SubtitleLayer` с Label, `ReticleLayer`. Правки только через `redot_scene_action`, вручную `.tscn` не редактировать.

## Порядок работ
1. `DocumentLayer` + 4 текстуры + open/close + режимы ввода; проверить читаемость кадрами 640×360.
2. Перелистывание, hover-края, наклон, сохранение последней страницы.
3. Ручка, строка, чернила, бины, 72%, дата.

5. Foley, ducking, validate, прогон по приёмке.

## Сделано
- Слои и прицел: точка 2×2 в центре, 6×6 над папкой, скрыт в оверлее.
- Оверлей: четыре страницы, открытие от проекции папки, закрытие кликом вне листа или Esc, наклон за курсором, притемнение и виньетка.
- Перелистывание: зоны 20 px по краям, подсветка края, лист уезжает за 0.35 с; на первой/последней зона неактивна; страница сохраняется.
- Проверено кадрами 640×360: документ читается; логика страниц проверена headless-скриптом.
- Гул вынесен в `sc001_hum.gd` (41 строка), оркестратор — 146 строк.

## Проверка
- `redot_code_intel(action="validate")` для каждого `.gd`.
- Прогон `--write-movie` с `--resolution 1280x720 --fixed-fps 30 --quit-after N`; проверка кадров: документ читается, лиц нет, пятно света, чернила, дата.
- Проверка записи звука: гул, стук, перо, выключатель, ducking −6 dB.
- Ручной прогон по пунктам «Приёмка» из `docs/scenes/SC001_signing.md`.

## Риски
- Читаемость 640×360 — главный риск; размер страницы и кегль подбираются по кадрам.
- 2D-оверлей скрывает 3D-руки во время подписи; видимый хват — отдельный арт-проход.
- Рантайм-синтез foley — временный по качеству; финальные WAV отдельной задачей.
- Переключение captured/visible мыши может ощущаться резким; проверить Esc и возврат в LOOK.
- Субтитры могут пересекаться с нижним краем документа; позиция уточняется по кадрам.

## Решённые противоречия
- **Фон при чтении.** Спека сцены говорила «слегка размывается», `art_direction §11` запрещает DOF. Решение автора: притемнение + виньетка, без blur/DOF. Спека сцены обновлена.
- **Перчатки.** `SC001_signing.md` — «перчатки в сцене нет»; `00_master` и `art_direction §16` всё ещё упоминают перчатки. Действует решение архивного плана: без перчаток. Синхронизация старых строк — отдельной правкой.
